# Cerca

App de actividades en tu localidad: un mapa de tu ciudad con música, caminatas, shows, cultura, deporte, gastronomía y planes de barrio.

## Flujo

1. **Elige tu ciudad** — usa la ubicación del teléfono o busca tu pueblo/ciudad.
2. **Explora el mapa** — cada pin es una actividad. Filtra por categoría y por cuándo (hoy / esta semana).
3. **Abre el detalle** — fecha, lugar, quién organiza y cómo llegar.
4. **Agenda** — lista cronológica y actividades guardadas.
5. **Publica** — toca `+`, marca el punto en el mapa y cuenta qué se arma.

Las actividades de ejemplo se generan alrededor de tu ciudad. Lo que tú publiques queda guardado en este navegador.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`.
